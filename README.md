Тестовое задание на позицию Junior+/Middle Frontend Разработчик
"Профилирование пользователей с фильтрацией и симуляцией
нестабильного API"
1. Кандидату предлагается сделать небольшое SPA-приложение на React + TS, которое:
 Показывает список "профилей пользователей"
 Позволяет фильтровать их по статусу (статусы на усмотрение кандидата)
 При клике открывается страница конкретного пользователя
2. Технические требования:
 Используется моковое API с симуляцией задержек и случайных ошибок (например, 30%
вероятность, что fetch вернёт ошибку)
 При ошибке необходимо показывать алерт и кнопку "Повторить"
 При загрузке отображаем лоадер
 Все данные валидируются через Zod
 Глобальное состояние (например, фильтр) — через Zustand
 Навигация — @tanstack/router + devtools
 Тестирование — vitest (1-2 простых unit + 1 интеграционный)
